## Featured Projects

### 🎮 [ClasherCity](https://github.com/Pranjal3125/ClasherCity)
A Paper plugin for a separate city world, plot management, protection, building tournaments, voting, judging, leaderboards, and configurable rewards.

**Built with:** Java · Paper API · SQLite · WorldGuard · Vault

### ⚔️ [Clasher Events](https://github.com/Pranjal3125/clasher-events)
A modular PvP events plugin for Clasher Network, with multiple event modes, arena management, kits, tournament flow, and player recovery.

**Built with:** Java · Paper API · WorldEdit · WorldGuard · YAML

### 🚌 [Real-Time Bus Driver Panel](https://github.com/Pranjal3125/real-time-bus-driver-panel)
An Android application concept for driver workflows and real-time bus location tracking, using GPS, motion detection, and a cloud backend.

**Built with:** Kotlin · Jetpack Compose · Android · AWS

### 🧱 [Clasher Resource Packs](https://github.com/Pranjal3125/Clasher-ResourcePacks)
A collection of resource-pack assets and custom visuals for the Clasher Network.
